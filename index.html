Analysis limitations

An indicator, not a verdict

CyberGuard uses URL-text rules, not live threat intelligence. Heuristic analysis cannot guarantee that a website is safe or malicious. It does not check DNS, reputation, certificates, redirects, or page content. Both false positives and false negatives are possible.
